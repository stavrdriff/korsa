Алюмінієві фасадні системи — повний комплекс

Теплий та холодний алюміній для будь-яких задач: вікна, двері, розсувні системи, стоєчно-ригельні фасади, навісні вентильовані фасади, вітрозахисні та сонцезахисні системи. Працюємо з провідними європейськими виробниками профілю — підбираємо оптимальну систему під задачу та бюджет.

🔥Теплий алюміній

Система з термомостом — спеціальною вставкою з полімеру, що блокує перенесення холоду. Для опалювальних приміщень: житло, офіси, ресторани, зимові сади. Високі показники теплозбереження.

❄️Холодний алюміній

Система без термомоста. Для неопалювальних об'єктів: балкони, тераси, вітрини, ворота, гаражі, склади, перегородки. Дешевший за теплий, але без теплоізоляції.

Віконно-дверні алюмінієві системи теплі та холодні

індивідуально

тепліАлюмінієві вікна

Профіль з термомостом 24-34 мм. Системи 69-72 мм монтажної ширини, 2-3 камери. Енергозбереження на рівні ПВХ. Максимальна висота до 3 м, ширина до 3,5 м.

Розрахувати

тепліАлюмінієві двері

Вхідні та міжкімнатні двері з теплого алюмінію. Великоформатні — до 3 м висоти. Енергозбереження, протизламна фурнітура, теплий поріг.

Розрахувати

холодніХолодне скління

Профіль F10/F38/46 без термомоста. Для неопалювальних балконів, лоджій, веранд, гаражів. Захист від опадів та вітру при мінімальній вартості.

Розрахувати

тепліШтульпові двері

Без центральної стійки — максимальний просвіт для широких прорізів. Виходи на терасу, ресторани, торговельні зали. Сумісність з усіма склопакетами.

під розмір

тепліДвері гармошка складні

Складні (book-fold) системи на 2-7 стулок. Повне відкриття отвору — стулки складаються «гармошкою» до однієї сторони. Для виходу на терасу, у зимовий сад.

Розрахувати

тепліПаралельно-зсувні

HST (Hebe-Schiebe-Tür) — підйомно-розсувні. Великі формати до 3×2,5 м, вага стулки до 400 кг. Для розкішних котеджів та комерції.

Розрахувати

холодніРозсувні балконні

Профіль Altest Pony або аналоги. Скління неопалювальних балконів, лоджій, веранд. Доступна ціна, легка стулка, плавне ковзання.

Розрахувати

холодніБезрамне скління панорама

Sliding / Accordeon — мінімально видимий профіль, максимальна прозорість. Для ресторанів, веранд, оглядових майданчиків.

проєктно

тепліСтандартна F50 фасад

Класична стоєчно-ригельна система зі ширшіною стояка 50 мм. Заповнення склопакетами до 60 мм. Можливість відкривних стулок у складі фасаду.

Розрахувати

тепліСтруктурні фасади

Безрамний вигляд зовні — стояки сховані за склом. Сучасний мінімалістичний дизайн для офісних будівель та елітної комерційної нерухомості.

Розрахувати

холодніСпайдерні фасади

Точкове кріплення скла павуками («spider»). Для атріумів, вхідних груп ТЦ, скляних входів готелів. Максимальна прозорість, унікальний дизайн.

Композитні касети

Алюмомінієво-композитні панелі (ACP/HPL) на підконструкції FN55. Для реконструкції фасадів існуючих будівель. Будь-який RAL, текстура під дерево, камінь, метал.

Розрахувати

Керамограніт та натуральні матеріали

Облицювання керамогранітом, фіброцементними плитами, керамікою, природним каменем. Енергоефективна вентильована теплоізоляція стіни.

Розрахувати

Профіль FN55 (підконструкція)

Алюмінієва підконструкція FN55 — універсальна основа для будь-яких облицювальних матеріалів. Розрахунок під вітрові навантаження. Гарантія 25 років.

опція до фасадних систем

Вітрозахисні екрани

Скляні панелі-екрани вздовж балконів, відкритих терас, оглядових майданчиків. Захищають від вітру, шуму, пилу, не закривають огляд. Безрамне або у профілі.

Розрахувати

Сонцезахисні ламелі

Горизонтальні або вертикальні алюмінієві ламелі. Фіксовані або поворотні. Зменшують перегрів приміщень, створюють тінь, додають архітектурної виразності фасаду.

Розрахувати

Біо-пергола тренд

Алюмінієва пергола з поворотними ламелями на даху. Регулювання сонця та повітря, водовідведення. Тераса під будь-яку погоду — для котеджів, ресторанів, готелів.
